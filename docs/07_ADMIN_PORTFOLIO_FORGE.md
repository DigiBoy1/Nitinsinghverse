# 07 --- Admin / Portfolio Forge

## Purpose

Portfolio Forge is the private control center for managing the public
portfolio without editing frontend content manually.

## Dashboard

Show useful summaries: - total projects - published projects -
certificates - unread messages - unread notifications - visitor totals
by period - recent activity

## Modules

-   Dashboard
-   Profile
-   About
-   Skills
-   Projects
-   AI / ML
-   GenAI
-   3D Experiments
-   Certifications
-   Badges
-   Education
-   Experience
-   Achievements
-   Learning Journey
-   GitHub
-   Resume / CV
-   Messages
-   Notifications
-   Visitor Analytics
-   Media Library
-   Site Settings

## Content controls

Each relevant module should support: - Create - View - Edit -
Delete/archive where appropriate - Publish/unpublish - Visibility -
Featured - Display order - Preview

## Workflow

Draft → Preview → Publish

## Projects

Admin should be able to manage the complete project/case-study dataset.

## Certificates

Admin should upload certificate media and maintain credential metadata.
Public UI must use a high-quality fullscreen viewer.

## Skills

Categories are admin-controlled rather than hard-coded. Suggested
initial categories: - Programming - Frontend - Backend - Database -
AI/ML - Generative AI - Tools & DevOps - Other

These are suggestions, not permanent restrictions.

## Media Library

Support reusable: - profile media - project images - screenshots -
certificates - badge images - videos - OG images - 3D assets

## Security

Admin routes and data must not be publicly accessible. Authentication
and database policies must be designed before exposing CRUD operations.

# 03 --- Information Architecture

## Public structure

HOME - Hero - About preview - What I Build - Featured Projects - Skills
preview - AI/ML - GenAI Lab - 3D Experiments - Certifications - Badges -
Education - Experience - Achievements - Learning Journey - GitHub -
Resume/CV - Contact

## Primary navigation

Keep the top navigation concise: - Home - About - Projects - Skills -
Lab - Certificates - Contact

Mobile uses a hamburger/menu pattern.

## Suggested routes

-   /
-   /about
-   /projects
-   /projects/:slug
-   /skills
-   /lab
-   /certificates
-   /resume
-   /contact

Additional routes can be added only when justified by requirements.

## Internal relationships

-   Projects link to skills.
-   Skills can link back to projects.
-   Certificates can reference skills.
-   Project case studies link to GitHub/live demo.
-   Resume links to projects/certifications.
-   Learning Journey can link to related skills/projects.

## UX principle

The homepage should quickly answer: 1. Who is Nitin? 2. What does he
build? 3. What proof exists? 4. How can I explore/contact him?

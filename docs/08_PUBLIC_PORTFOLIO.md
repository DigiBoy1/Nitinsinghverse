# 08 --- Public Portfolio

## Homepage goal

Within a short visit, a visitor should understand: - who Nitin is - what
he builds - strongest proof - where to see more - how to contact him

## Hero

Nitin Singh AI/ML Student · Full-Stack Developer

> Building intelligent, real-time and interactive web experiences.

CTAs: - View Projects - View Resume

Social: - GitHub - LinkedIn - Email

## About

Explain identity, current focus and interests without exaggerated
claims.

## Featured project

### Mood Wala

Position as: **Real-time synchronized social listening platform**

Do not describe it merely as a music website.

Suggested case-study structure: - Overview - Problem - Idea -
Architecture - Features - Technology - Challenges - Solutions -
Screenshots/Demo - What I Learned - Links

Only include technical claims that match the actual implementation.

## Skills

Show real capabilities with context and project/certificate proof.

Avoid fake numeric percentages.

Possible states: - Learning - Familiar - Intermediate - Advanced

Use only the level that can be honestly supported.

## AI/ML

Show actual projects/experiments. Do not fill the section with generic
claims.

## GenAI Lab

Frame as exploration when work is still being built.

## 3D Experiments

Show actual interactive experiments and their source/technology when
available.

## Certificates

Thumbnail → fullscreen → details → optional verification.

## Badges

Separate visual area from certificates.

## Resume

Provide View Resume and Download CV actions.

## Contact

Name, email, subject, message. Keep the form simple and accessible.

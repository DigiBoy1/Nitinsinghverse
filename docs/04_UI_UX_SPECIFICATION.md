# 04 --- UI/UX Specification

## Visual direction

-   Dark
-   Futuristic
-   Premium
-   Minimal
-   High-quality typography
-   Restrained glow and gradients
-   Subtle depth
-   Smooth but purposeful motion

## Responsive priority

1.  Mobile
2.  Tablet
3.  Desktop

## Mobile requirements

-   No horizontal scrolling.
-   Touch-friendly controls.
-   Comfortable spacing.
-   Readable typography.
-   Fast loading.
-   Lightweight 3D/fallback.
-   Fullscreen certificate viewer.
-   Easy CV access.
-   Easy contact.
-   Respect device safe areas where relevant.

## Desktop requirements

-   More spacious composition.
-   Richer 3D where useful.
-   Strong project presentation.
-   Clear navigation.
-   No excessive visual clutter.

## Three.js strategy

Three.js should demonstrate technical ability, not merely decorate every
section.

Desktop: - richer interactive hero/experiments

Tablet: - reduced complexity

Mobile: - lightweight scene or fallback when needed

## Animation rules

-   Prefer subtle transitions.
-   Avoid animation that delays content.
-   Avoid continuous heavy animation.
-   Respect prefers-reduced-motion.
-   Never sacrifice readability for effects.

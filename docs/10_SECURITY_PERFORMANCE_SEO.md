# 10 --- Security, Performance & SEO

## Security

### Admin

-   Protected authentication.
-   Protected routes.
-   Secure sessions.
-   Database row-level/access policies.
-   Input validation.
-   Output sanitization where required.
-   Secure file access.
-   Environment secrets only on server-side.
-   Logout/session expiry strategy.

### Public forms

-   Validation
-   Spam/abuse protection
-   Safe error messages
-   Rate limiting where appropriate

### Privacy

Collect only what is useful. Avoid unnecessary exact identity or
personal information. Visitor analytics should be privacy-conscious and
anonymous where possible.

## Performance

### General

-   Mobile-first loading.
-   Optimize images.
-   Lazy load below-the-fold media.
-   Compress videos.
-   Optimize 3D models/textures.
-   Minimize JavaScript.
-   Avoid unnecessary dependencies.
-   Optimize fonts.
-   Use sensible caching.
-   Provide loading states.

### Three.js

-   Avoid oversized textures/models.
-   Limit scene complexity.
-   Pause/reduce effects when not visible where practical.
-   Provide mobile fallback.

### Accessibility

-   Semantic HTML.
-   Keyboard navigation.
-   Visible focus.
-   Good contrast.
-   Alt text.
-   Accessible buttons/labels.
-   Reduced motion.
-   Touch-friendly targets.

## SEO

Required foundations: - Unique title - Meta description - Canonical -
sitemap.xml - robots.txt - Open Graph metadata - Semantic HTML -
Appropriate structured data - Crawlable project pages - Fast
performance - Genuine, descriptive content

Brand SEO objective: Build a strong presence for "nitinsinghverse"
through consistent branding, useful project pages and genuine content.
Avoid keyword stuffing.

## SEO content principle

Project case studies should contain real technical detail because they
provide both proof and search value.
